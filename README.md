# The Feline Graph Chronicles

Sistema Java para resolver problemas de grafos mediante algoritmos clásicos, inspirado en las heroínas Pola, Minerva, Nina y el villano Limón.

## Requisitos

- JDK 17 o superior
- IntelliJ IDEA (recomendado)

## Clonar el proyecto

1. En IntelliJ: **File > New > Project from Version Control**
2. Pegar la URL del repositorio:
   ```
   git clone https://github.com/juliMR-23/Parcial_Compi.git
   ```
3. Seleccionar JDK 17 como SDK del proyecto
4. Esperar a que IntelliJ indexe las dependencias

## Ejecutar

Ejecutar `src/Main.java` 

## Estructura

```
src/
├── Main.java
├── ui/           → Interfaz gráfica (Swing)
├── utils/        → Parseo de entrada
├── algorithms/   → Algoritmos de grafos
└── models/       → Estructuras de datos
```
